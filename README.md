## 🏗️ Architecture Microservices

```text
                         ┌─────────────────────┐
                         │      Frontend       │
                         │ React / Angular /   │
                         │      Vue.js         │
                         └──────────┬──────────┘
                                    │
                                    ▼
                         ┌─────────────────────┐
                         │     API Gateway     │
                         │  Spring Cloud       │
                         │     Gateway         │
                         └──────────┬──────────┘
                                    │
                 ┌──────────────────┼──────────────────┐
                 │                  │                  │
                 ▼                  ▼                  ▼
        ┌────────────────┐ ┌────────────────┐ ┌────────────────┐
        │ User Service   │ │ Product        │ │ Order Service  │
        │ Spring Boot    │ │ Service        │ │ Spring Boot    │
        │                │ │ Spring Boot    │ │                │
        └───────┬────────┘ └───────┬────────┘ └───────┬────────┘
                │                  │                  │
                └──────────────────┼──────────────────┘
                                   │
                                   ▼
                         ┌─────────────────────┐
                         │   Eureka Server     │
                         │  Service Discovery  │
                         └─────────────────────┘

                    ┌─────────────────────────┐
                    │      Apache Kafka       │
                    │  Event / Messaging      │
                    └─────────────────────────┘

                    ┌─────────────────────────┐
                    │        Keycloak         │
                    │   OAuth2 / OIDC / Auth  │
                    └─────────────────────────┘
```
